# ZIPP 0.0.40

A major multi-round performance release delivering large speedups across real-world Python and JavaScript applications, the official JS and Python benchmark suites, the regex engine, WebAssembly / `safe-sandbox` builds, and the PHP and Rust runtimes — plus readable JS function names in Linux JIT perf-map labels and routine dependency updates.

Thank you to [@codeandsolder](https://github.com/codeandsolder) for contributing PR [#110](https://github.com/f2i-com/zipp.org/pull/110) (*"perf: include JS function names in Linux JIT perf-map labels"*), which appends sanitized `FuncProto.name` labels (`fn4264_querySelectorAll_whole-fn`) to `ZIPP_PERF_MAP=1` ranges while keeping zero overhead when perf-map profiling is off! Your profiling feedback and PR directly made DOM-heavy JS profiling much clearer and helped drive several of the hot-path wins in this release.

## New in 0.0.40

- **Linux JIT Perf-Map Function Labels ([#110](https://github.com/f2i-com/zipp.org/pull/110), by [@codeandsolder](https://github.com/codeandsolder)):**
  - Appends sanitized JS function names (capped to 64 ASCII-safe characters) to `ZIPP_PERF_MAP=1` symbols (`fn{id}_{name}_{tier}`), retaining numeric-only labels for anonymous functions and preserving zero overhead when perf-map profiling is disabled.
- **JavaScript VM, x86-64 JIT & Allocator/GC Throughput:**
  - Prevents enclosing `MEM` OSR regions from shadowing inner `INT`/`DOUBLE` register-homed regions (unlocking `DOUBLE` OSR for `webforai`'s `scoreBlocks` scoring loop) and adds an exact IEEE-754 4×-unrolled `Float32Array`/`Float64Array` MAC inner-loop prefix for `affine`.
  - Admits `ToConcatKey`, `GetIndexConcat`, `ArrayFrom`, collection constructors, spread calls, and `StrConcat` into Tier-C / JIT helper lanes; wires `emit_cross3_dyn_stub` into `region_mem` calls; adds inline megamorphic class getter/setter dispatch and widens `class_member_cache` (mixing `w1`, longer inline keys, and class-only GC invalidation).
  - Eliminates unconditional `array_snapshot` clones in `find`/`findIndex`/`some`/`every`/`findLast`/`reduce`/`forEach`, avoids redundant subject clones and per-match `Vec<u8>` allocations in `regex_replace`, adds `replaceAll` / `match` / `split` fast paths, and enables `Set`/`Map`/`String` iteration in `jit_get_iterator`/`jit_iter_next`.
  - Adds a 2048-slot VM `static_append_shape_cache` for object literals, pooled well-formed string concatenation (`concat_wellformed_in_buf`), `Closure`/`PyAttrs` slot recycling in `Heap::free_slot`, fast-pathed ASCII `toUpperCase`, fast `WeakMap`/`WeakSet` proven lanes + `FxHashMap`/`FxHashSet` ephemeron GC tracing, and faster closure capture resolution.
- **Python VM, JIT & Runtime Throughput:**
  - Raises `PyAttrs` `DEPTH_MAX` from 64 to 128 so large stateful instances (such as `html2text.HTML2Text` with 84 fields) stay in layout-mode `PyAttrs` without spilling to `PyTable`.
  - Routes hot Python object allocations (`seq`, `inst`, `exc`, `dict`, `slice`, `frame`) through `'static` `OnceLock<StaticKeyPlan>` ready-object pools, and caches `STR_HAS_SURROGATE` in `JsStr::memo_state` so BMP Unicode strings stay O(1) without O(N²) rescan cliffs.
  - Adds native `PyTable` hashing/equality and native subscripting/len/truth for unmodified `str` and `tuple` subclasses (`bs4.NavigableString`, `soupsieve` `NamedTuple`s), collapses redundant cold `subscript_get` misses, and ensures strictly non-allocating ASCII indexing in `py_get_item`.
  - Adds fused `PyTruth` (with an inline x86-64 fast path for `bool`/`None`/small `int`), non-allocating `PyGetAttr`/`PySetAttr` fast-hit prefixes, dict-less `no_dict` support in `py_method`/`py_attr_get` (`__slots__`/`NamedTuple`), fast `py_cls_of` slot checks, `memchr` + single-borrow array scan in `py_in`, native `py_re` spans, exception construction fast paths, and expanded `PY_STRM` / `isinstance` tuple / `ord` / `format` / `collections.deque` fast paths.
- **Regex (`regress-fork`), WebAssembly / `safe-sandbox`, Compiler & PHP/Rust Runtimes:**
  - Improves `regress-fork` start-predicate extraction (zero-width assertions, `Node::Char`, optional leading loops, lookbehinds, anchored alternations), adds UTF-16 `unit_may_start` prefiltering, and reuses `MatchAttempter` scratch buffers.
  - Re-enables pure-safe interpreter IC hit paths, metered superinstructions, safe `capture.rs` memoization, faster `to_js_bounded` JSON marshalling, and expanded regex caching in `zipp-wasm` / `safe-sandbox` (preserving zero `unsafe` and the audited 51-function WASM import surface).
  - Linearizes `compile/string_accum.rs`, deduplicates ESM specifier resolution, and replaces O(N²) array/map operations in the PHP and Rust runtimes with O(1) ring buffers and cached cursors.
- **Dependency Maintenance ([#111](https://github.com/f2i-com/zipp.org/pull/111), [#112](https://github.com/f2i-com/zipp.org/pull/112), [#113](https://github.com/f2i-com/zipp.org/pull/113)):**
  - Updates `regex` (`1.13.1 → 1.13.2`), `pollster` (`1.0.1 → 1.0.3`), and `@cloudflare/vite-plugin` (`1.69.1 → 1.70.1` in `landing/`).
