# ZIPP 0.0.41

A four-phase real-world performance release delivering major speedups across production JavaScript and Python applications, Python generators (`yield from` / `send` / bulk drain), regular expressions, class/metaclass attribute caches, x86-64 JIT inlining, and heap allocation throughput — while preserving byte-identical output and zero `unsafe` in `safe-sandbox` / WebAssembly builds.

## Benchmark Highlights (`v0.0.41` vs. `v0.0.40`, Node.js & CPython)

All measurements below were captured on Windows x86-64 with byte-identical output against **Node.js v24.19.0** and **CPython 3.13.14**, comparing matched local **non-PGO fat-LTO** builds of `v0.0.40` (`9b70d2d3`) and `v0.0.41` (`e39f4ebe`) on the same machine. Release PGO builds of `v0.0.41` add further gains on top of these numbers.

## New in 0.0.41

- **JavaScript VM, x86-64 JIT & Regex Throughput:**
  - Adds an inline x86-64 `GetProp` fast path for pristine `%String.prototype%` methods (`indexOf`, `slice`, `startsWith`, `endsWith`, `includes`, `trim`, `split`, `replace`, etc.), cutting DOM and text-heavy property lookup overhead.
  - Eliminates leaf-inlining bail storms in large DOM walkers (`defuddle`), removes legacy `lexical_this` `call_value` detours and redundant `warm_mega_method_memo` scans in `jit_region_call_impl`, and expands `region_mem` / `proto_mem` / OSR / IC specialization.
  - Adds a zero-`mi_malloc` streaming `regex_replace_ascii` fast path and a direct `RegExpMethod::Match` lane in `proxy_regexp.rs`.
  - Filters `inherit_private_brands` via a cached `func_needs_brands` predicate so class constructors without private brand fields skip brand-table work.
- **Python Generators, `yield from`, Iterators & Regex:**
  - Implements native PEP 380 `yield from` (`PY_YFSTEP` / `__zipp_py_yfstep`), native `generator.send`, `next`, `list`, `tuple`, bulk `PY_ITER` / generator drain into dense arrays, and a native `stringIter` fast path (`kind=5`).
  - Adds lazy zero-`Array`/zero-`SlotTable` ASCII span-backed Python `re.Match` objects alongside native module-level `re.sub` / `re.search` / `re.match` / `re.fullmatch` fast lanes, eliminating temporary match allocations on misses and unindexed matches.
  - Adds a native `textwrap.wrap` / `fill` fast path (with zero `unsafe` under `safe-sandbox` / WebAssembly builds).
- **Python Object Model, Descriptors, Subclasses & JIT ICs:**
  - Switches `R.func` to a zero-copy 32-slot record layout with lazy `dict: null` allocation.
  - Caches type-object attributes (`TYPE_CLASS_ATTR`) and metaclass `@property` getters (`TYPE_ATTR_FN`) in Python ICs, adds direct `@property` and bound-generator call ICs (`CALL_BOUND_GEN`), and lowers 2-argument `super(Cls, self).method(...)` directly in the Python frontend.
  - Adds native builtin-subclass `__contains__` fast lanes (`SUB_DICT_IN`, `SUB_SEQ_IN`, `SUB_STR_IN`) for workloads such as BeautifulSoup / SoupSieve.
