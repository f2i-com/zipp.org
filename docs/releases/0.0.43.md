# ZIPP 0.0.43

A performance and engine-efficiency release. The Tier O optimizing JIT is now enabled by default on x86-64 (`ZIPP_NO_OPT=1` opts out), backed by direct register-to-register calls (D3), polymorphic and depth-2 inlining, zero-cell immutable value captures (`Upvals::Vals`), inline closure upvalues, native `super()` / derived-constructor fast paths, and broad interpreter, GC, RegExp, and WebAssembly improvements.

Compared with `v0.0.42`, real-world applications run **21% to 35% faster** in default mode, pure interpreter execution (`ZIPP_NOJIT=1`) runs **14% to 21% faster**, `bench/real` improves by **2.8%** across all 13 programs (**4.0%** across the 10 headline programs), and WebAssembly builds are **1.6% to 1.9% smaller** while running faster on every steady-state workload.

## Benchmark Highlights (`v0.0.43` vs. `v0.0.42`, Node.js)

## New in 0.0.43

- **Tier O optimizing JIT enabled by default (x86-64):**
  - Tier O is now on by default (`ZIPP_NO_OPT=1` disables it), including automatic promotion of hot OSR `MEM` loops while preserving specialized register-homed and field-stream loop reducers.
  - Added **D3 direct register-to-register calls**, getter dispatch, commit-tail mutable callees, inline `Boolean(x)` / `MakeClosure` / `NewEmptyColl`, and dead-end throw-block elision.
  - Added polymorphic, closure, and depth-2 inlining, `InlineMegaGetProp`, LICM/GVN (including pure `Length` and `charCodeAt` hoisting), enum switch jump tables, constant propagation, cold-path outlining, and shared stubs.
  - Lowered `charCodeAt` to unboxed `I32`, added inline constant-key `GetIndex` and writable shaped `SetIndex` ICs, mixed packed-ASCII `strict_eq` (`bit-63` mirror), native `for-of` `finally` routing, `Op::StrCase` / `Op::StrAppend`, and Tier O private-field and `IterToArray` fast paths.
  - Eliminated Tier O deopt storms via Tier C shape harvesting, `GuardFid` deopt separation, and spill-slot recycling.
- **Closures, objects, and classes:**
  - Added zero-cell inline immutable value captures (`Upvals::Vals`, up to 3 values stored directly inside the 64-byte `HeapObj::Closure`, including top-level hoisted function declarations and TDZ-free `const` bindings) and inline `1..=2` cell upvalues (`Upvals::Inline`) with packed `UpvalCache`, cutting `webforai` swept objects by 20% and GC collections by 21%.
  - Added native `<stub:super_ctor>`, derived-constructor chain caching, frame-free derived constructors and ctor-less subclasses, inline `ThisCheck`/`SuperCtorFetch`, and fast `ClassData` private fields.
  - Cached function and class static data properties in site ICs and `dict_prop_memo`, added a guarded `fn_props` set fast path, inline `AddWay`/`SymAdd` transitions, planned `InitDataProp`, and keyed-memo `in` (`<stub:has_prop>`).
  - Routed `fn.apply(thisArg, array)` directly into the native call stub with zero-alloc rest-apply forwarding, and added direct `Array.from` iterators and identity-hashed `WeakMap`/`WeakSet` tables.
- **Interpreter, GC, RegExp, and WebAssembly:**
  - Shrunk interpreter dispatch/native frames, optimized TypedArray reads (16-slot cache), global routing, `join`/`split`/spread, and safe-sandbox recycle pools (`obj_pool` / `arr_pool` enabled for non-JIT/WASM builds) plus zero-alloc Proxy descriptors.
  - Accelerated GC with inline `ReadyCells` / `ReadyClosures` slab refills, zero-alloc GC scratch, major-only pool address sorting, lazy `WeakMap` `GEN_WEAK_KEY`, empty `Map`/`Set` `GEN_LEAF` tracking, and `key_pool_used` gating.
  - Optimized RegExp with compact `RegexpProtoFastSlots` across all 7 prototype methods, a `RegExpCore` cache, and zero-match / single-match / pooled-buffer functional-replacer fast paths.
  - Reduced WebAssembly module size by folding static env switches, dropping dead lazy/profiler/Temporal code in WASM/lite builds, and outlining cold capture/compiler paths.
- **Fixes:**
  - Cleared `pending_throw` across all abrupt `IteratorClose` paths (`Object.fromEntries`, `Map`/`Set`/`WeakMap`/`WeakSet` constructors, `Array.from`, and iterator zip helpers) so JIT deopts inside `return` hooks cannot abort with the outer exception.
  - Fixed `ObjMap::side_table_single` `key_bytes` accounting, prevented null-prototype reads in `jit_inline_mega_get_prop` from poisoning the shared shape absent-property memo, fixed derived-class `super()` spec semantics and Tier O `wide_uninit_mask`, and cleaned `aarch64` `-D warnings` builds.
