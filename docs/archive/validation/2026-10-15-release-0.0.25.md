# Release 0.0.25: the reported embedding bugs, and the safe-sandbox interpreter past Bellard's QuickJS - 2026-10-15

Covers the 55 commits from `v0.0.24` (`a82ad0bb`) to `eab501f9`, plus
the commit that prepares the release and adds this record:

- the site refresh for 0.0.24 (`0b3e9ba4`);
- the fixes for the ten issues @takahashim reported after 0.0.24, #46 to
  #55, and their tests (`19889bfa`, `5aad4211`);
- the embedding performance pass after #50: eval and `new Function` code
  reaching the JIT, script and published globals kept in their slots,
  WeakMap/WeakSet lanes in compiled code, direct entry into a compiled
  frame call (`184dfdb3` to `38f77a8d`);
- the safe-sandbox pass against QuickJS-NG and Bellard's QuickJS
  (`8c4d4e97` to `a4e1b23d`), the sparse array overlay (`d0c9ed0b`), the
  JIT own-`push` fix (`03a2e33e`) and the interpreter work after it
  (`908fc26d` to `38f58e6e`);
- the canonical capture's record (`8df0dd24`);
- the safe-sandbox and wasm eval-global pool (`3e8a5d07`) and the
  boundary test the sparse overlay outdated (`eab501f9`).

Every commit carries `[skip ci]`; CI and the security workflow are
dispatched by hand.

## The reported issues

The reproductions of #49 to #52, copied from the issues, ran three times
each in each mode (medians are in the release notes' table). #54's ran
once in each mode and prints `2`, Node's answer, in 0.0.24 too: the
defect existed only on `main` between `5762df5a` and `476de138`. #50's program throws
"too many global bindings" in 0.0.24's and `38f58e6e`'s safe-sandbox
builds, and runs (12 ms before and after the 5,000 globals) on
`3e8a5d07`.
