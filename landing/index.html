Zipp is a JavaScript and Python engine written in Rust.

A from-scratch ECMAScript engine with an explicit-frame register VM, native x86-64 and ARM64 JIT tiers, a generational garbage collector, an experimental Python 3 frontend that compiles to the same bytecode, an interpreter-only WebAssembly sandbox for the browser, and WebGPU/WebGL2 compute graphs. Open source under Apache-2.0.
