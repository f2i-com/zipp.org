ZIPP is a portable polyglot runtime.

ZIPP, the Zippy Interpreter for Polyglot Programming, is one Rust register-bytecode VM that several languages compile to, so programs in different languages share one runtime, one sandbox and one set of embeddings: the native CLI, a Rust library, and WebAssembly in browsers, Node, Deno and Bun. JavaScript (ES2025, 99.999% of the pinned Test262 corpus) and Python (an experimental subset with a bundled torch subset) are the languages it supports today, and the VM is designed for more. Open source under Apache-2.0.
